# MAHARA — интерактивный прототип интернет-магазина

Рабочий адаптивный прототип на чистых HTML, CSS и JavaScript. Внешние библиотеки не требуются.

## Что внутри

- `index.html` — главная страница.
- `catalog.html` — каталог с фильтрами и сортировкой.
- `styles.css` — дизайн, адаптивность и анимации.
- `script.js` — меню, фильтры, быстрый просмотр, корзина, поиск и интерактивные эффекты.
- `assets/images` — оптимизированные фотографии.
- `preview` — изображения десктопной и мобильной версий.

## Как запустить

Самый простой вариант — открыть `index.html` в браузере.

Для корректного поведения всех браузерных функций лучше запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

## Реализовано

- адаптивная версия от 320 px;
- переливающийся красный логотип на первом экране;
- параллакс фотографий;
- появление блоков при прокрутке;
- hover-анимации и смена фотографии товара;
- мобильное меню;
- каталог, фильтры и сортировка;
- быстрый просмотр товара;
- выбор размера;
- демонстрационная корзина с сохранением в `localStorage`;
- горизонтальные мобильные слайдеры.

Цены, контакты, ссылки на соцсети и часть текстов сейчас демонстрационные — перед публикацией их нужно заменить на реальные данные бренда.
