# MAHARA — интерактивный прототип интернет-магазина

Рабочий адаптивный прототип на чистых HTML, CSS и JavaScript. Внешние библиотеки не требуются.

## Что внутри

- `index.html` — главная страница.
- `catalog.html` — каталог с фильтрами и сортировкой.
- `product-*.html` — восемь статических страниц моделей со ссылками из каталога.
- `catalog-data.js` — общий источник данных и карточек для браузера и генератора.
- `admin.html` — демонстрационная CMS: тексты и фотографии главной, названия, цены, размеры и фотографии товаров.
- `cms-data.js` — общая модель контента и сохранение демо в браузере (IndexedDB).
- `admin.css`, `admin.js` — оформление редактора, формы и живой предпросмотр.
- `seo.config.json` — основной адрес сайта `https://maharussia.ru/`.
- `robots.txt`, `sitemap.xml` — настройки обхода и карта канонических страниц.
- `styles.css` — дизайн, адаптивность и анимации.
- `script.js` — меню, фильтры, быстрый просмотр, корзина, поиск и интерактивные эффекты.
- `assets/images` — оптимизированные фотографии.
- `preview` — изображения десктопной и мобильной версий.

## Как запустить

Самый простой вариант — открыть `index.html` в браузере.

Для корректного поведения всех браузерных функций лучше запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

После этого открыть `http://localhost:8000`.

Панель управления доступна по ссылке «Управление» в хэдере или на `http://localhost:8000/admin.html`. Измените поля, загрузите фотографии и нажмите «Сохранить изменения»: главная, каталог, страницы товаров и корзина используют сохранённые данные. Уже открытые вкладки этого сайта также получают обновления. «Сбросить демо» возвращает исходный контент.

Демо работает без бэкенда и подходит для статического хостинга, включая GitLab Pages. Изменения сохраняются только в текущем браузере для адреса этого сайта; у других пользователей будет исходный контент. Для проверки переходов и сохранения используйте локальный HTTP-сервер, а не `file://`. Очистка данных браузера удаляет правки. Админка исключена из sitemap и помечена `noindex`.

## Реализовано

- адаптивная версия от 320 px;
- переливающийся красный логотип на первом экране;
- параллакс фотографий;
- появление блоков при прокрутке;
- hover-анимации и смена фотографии товара;
- мобильное меню;
- каталог, фильтры и сортировка;
- быстрый просмотр товара;
- выбор размера;
- демонстрационная корзина с сохранением в `localStorage`;
- горизонтальные мобильные слайдеры.

Цены, контакты, ссылки на соцсети и часть текстов сейчас демонстрационные — перед публикацией их нужно заменить на реальные данные бренда.

## SEO и доступность

Каталог и описания моделей доступны в исходном HTML без JavaScript. На каждой странице есть уникальные title/description, canonical, Open Graph/Twitter и JSON-LD. Структурированные данные описывают бренд, каталог, хлебные крошки и модели; демонстрационные цены не публикуются как Offer, наличие и отзывы не выдумываются.

После изменения товаров в `catalog-data.js`, домена в `seo.config.json` или общей навигации/окон в `catalog.html` пересоберите статические страницы:

```bash
node tools/build-seo.cjs
```

Генератор обновляет карточки в главной и каталоге, метатеги, страницы моделей, sitemap и robots.txt. Главную и каталог можно редактировать вручную; содержимое между маркерами `products:` и головы страниц создаёт генератор. Для нового товара укажите уникальные `id`/`url`, реальные размеры фото и проверенное описание.

Независимая локальная проверка:

```bash
node tools/audit-seo.cjs
```

Проверка редактирования, сохранения, фотографий, каталога, корзины и мобильной версии:

```bash
node tools/audit-cms.cjs
```

Для неё нужен Playwright (переменная `PLAYWRIGHT_MODULE` может указать путь к модулю) и Chrome либо браузер Playwright. Проверка запускает локальный HTTP-сервер и не передаёт содержимое сайта внешним сервисам.

Панели поиска, корзины, меню и мобильных фильтров поддерживают Tab, Escape, возврат фокуса и inert для фона. Выбранные размеры и фильтры объявляют состояние; при отключённом JavaScript остаются навигация, фотографии, описания и размеры моделей.

Перед запуском на домене замените демонстрационные сведения, подключите оформление/подписку и опубликуйте содержимое корня проекта через HTTPS. На хостинге настройте перенаправления HTTP → HTTPS и www → основной домен, отдачу 404 для отсутствующих страниц, сжатие HTML/CSS/JS и кеширование изображений. Sitemap подаётся в Google Search Console и Яндекс Вебмастер после публикации. Проверка live-индексации и Core Web Vitals требует работающего домена.
